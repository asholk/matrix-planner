# Matrix planner

[English](README.en.md)

Плагин Obsidian для планирования по матрице Эйзенхауэра: задачи в четырёх квадрантах, календарь с событиями и быстрыми заметками, обои экрана блокировки с неделей и матрицей. Все данные — обычные заметки Markdown в вашем хранилище: их можно открыть, изменить и синхронизировать как любые другие заметки.

Плагин работает на Windows, macOS, iPhone, iPad и Android. С версии 0.2 он сам синхронизирует задачи и события с «Календарём» iOS через iCloud — отдельное приложение не нужно. Приложение-компаньон для виджетов iPhone в разработке и в эту поставку не входит.

## Возможности

- **Задачи.** Матрица 2×2: «Важно и срочно», «Важно», «Срочно», «Когда-нибудь». Срок с датой и временем, повтор (каждый день, неделю, месяц, год), напоминание, высокий приоритет. Перетаскивание между квадрантами, перенос на завтра, фильтр **Выполнено** с возвратом в работу, автоматический перенос выполненных в архив.
- **Календарь.** Лента недели, список дня (весь день, по времени, заметки), временная шкала и вид месяца. Кнопка **+** добавляет задачу, событие или заметку сразу в выбранный день.
- **События и быстрые заметки.** Событие — заметка с началом, концом, цветом, значком и повтором. Быстрая заметка — заметка с датой, видна в своём дне календаря.
- **Синхронизация с «Календарём» iOS.** Через iCloud (CalDAV): события в обе стороны, задачи со сроком — в календарь с напоминаниями, подписки ICS для просмотра. Работает на всех платформах.
- **Обои экрана блокировки.** Шаблоны «Матрица» и «Календарь», фон (картинка из хранилища, однотонный, градиент), палитры. Плагин сохраняет PNG на 7 дней вперёд, а на iPhone и iPad запускает быструю команду, которая ставит обои. Кнопка **Получить фото** отдаёт картинку на сегодня как фото.
- **Вкладка «Настройки».** Параметры плагина открываются прямо в Планировщике, без перехода в настройки Obsidian.
- **Ссылки `obsidian://planner`** — открыть вкладку, создать задачу, открыть элемент.
- **Проверка целостности.** Дубликаты ID, конфликтные копии, повреждённые свойства — в списке **Требуют внимания**.
- Русский и английский интерфейс; начало недели и формат времени — по региону или вручную.

## Установка

Плагин пока не опубликован в каталоге сторонних плагинов. Его можно установить через BRAT или вручную.

### Через BRAT

Подходит для iPhone и iPad: не нужно копировать файлы в скрытую папку `.obsidian`, а обновления приходят сами.

1. Установите плагин **BRAT** из каталога: **Настройки → Сторонние плагины → Обзор**, найдите «BRAT», затем **Установить** и **Включить**.
2. Откройте **Настройки → BRAT → Add beta plugin**.
3. Вставьте адрес репозитория `https://github.com/asholk/matrix-planner` и нажмите **Add plugin**.
4. Включите **Matrix planner** в **Настройки → Сторонние плагины**.

### Вручную

1. Скачайте `main.js`, `manifest.json` и `styles.css` из релиза (или соберите их сами — см. [Разработка](#разработка)).
2. Создайте папку `<хранилище>/.obsidian/plugins/matrix-planner/` и положите в неё эти три файла.
3. Перезапустите Obsidian или обновите список плагинов: **Настройки → Сторонние плагины → Установленные плагины**.
4. Включите **Matrix planner**.
5. Откройте Планировщик значком на ленте (**Открыть Планировщик**) или командой **Открыть задачи**.

На iPhone и iPad папка `.obsidian` скрыта в «Файлах». Проще всего скопировать плагин на компьютере и синхронизировать хранилище, либо использовать приложение для работы с файлами, которое показывает скрытые папки.

При первом запуске плагин создаёт в корне хранилища заметку-маркер `matrix-planner.md` и папку `Планировщик/`.

## Данные в хранилище

```text
<хранилище>/
├── matrix-planner.md              # маркер: root, schema, vault_id
└── Планировщик/
    ├── Задачи/                    # одна заметка — одна задача
    │   └── Архив/ГГГГ-ММ/         # выполненные (если включён перенос в архив)
    ├── События/                   # одна заметка — одно событие
    │   └── Удалённые/             # удалённые в «Календаре» iOS
    ├── Заметки/                   # быстрые заметки с датой
    ├── Матрица.md                 # названия, цвета и значки квадрантов
    ├── _system/                   # служебные JSON: кэш календаря, метки удаления
    └── Обои/<профиль устройства>/ # PNG обоев
```

Корневую папку можно изменить в настройках. Название заметки — название элемента; связь держится на свойстве `id` (ULID), поэтому заметки можно переименовывать и перемещать внутри корня. Неизвестные свойства и текст заметки плагин не трогает.

| Тип | Основные свойства |
| --- | --- |
| Задача (`type: task`) | `id`, `quadrant` (`do`, `plan`, `urgent`, `someday`), `due` (`2026-10-11` или `2026-10-11T09:00`), `repeat`, `repeat_anchor`, `remind`, `priority`, `done`, `completed`, `completions`, `created` |
| Событие (`type: event`) | `id`, `start`, `end`, `all_day`, `tz`, `repeat`, `color`, `icon`, `calendar_id`, `url` |
| Быстрая заметка (`type: note`) | `id`, `date` |

Время в свойствах «плавающее»: оно трактуется в часовом поясе устройства. Подробности — в [docs/contracts.md](docs/contracts.md), формат служебных файлов — в [docs/system-json.md](docs/system-json.md).

Синхронизация:

- Если хранилище синхронизируется через Obsidian Sync, включите **Другие типы файлов**, иначе `_system/*.json` не попадут на другие устройства.
- Папку `Обои/` рекомендуется исключить из синхронизации: картинки большие, а каждое устройство рисует свои.
- Скрытые папки (с точкой) плагин не использует.

## Синхронизация с «Календарём» iOS

Плагин подключается к iCloud по протоколу CalDAV — так же, как «Календарь» на Mac или Windows. Синхронизация работает на компьютере, iPhone, iPad и Android; достаточно включить её на одном устройстве, например на основном компьютере.

Что синхронизируется:

- **События** — в обе стороны: событие, созданное в Планировщике, появляется в «Календаре» iPhone, а изменения в «Календаре» возвращаются в заметку. Если событие изменили в обоих местах, побеждает заметка. Событие Планировщика, удалённое в «Календаре», переносится в папку `События/Удалённые/`.
- **Задачи со сроком** — в календарь для записи (по умолчанию «Планировщик») с напоминаниями: их показывает iOS. Выполненные задачи можно тоже записывать — параметр **Выполненные задачи в календаре**.
- **Показываемые календари** — события выбранных календарей iCloud видны в Планировщике. Они попадают в `_system/calendar-cache.json`, поэтому видны и на устройствах, где синхронизация не включена.
- **Подписки ICS** — календари по ссылке `webcal://` или `https://`, только для просмотра.

Как подключить:

1. Создайте пароль приложения: откройте [account.apple.com](https://account.apple.com), войдите, выберите **Вход и безопасность → Пароли приложений** и создайте пароль, например «Планировщик». Обычный пароль Apple ID не подойдёт.
2. В Планировщике откройте вкладку **Настройки** (или **Настройки → Matrix planner**) и найдите раздел **Календарь iOS**.
3. Включите **Синхронизация**, укажите Apple ID и пароль приложения, нажмите **Проверить** у **Проверить подключение**.
4. Выберите **Календарь для записи** — плагин может найти или создать календарь «Планировщик» — и календари для показа.

Пароль хранится только на этом устройстве (в хранилище секретов Obsidian 1.11.4 и новее, иначе — в локальном хранилище приложения) и не попадает в хранилище заметок и в синхронизацию. Apple ID хранится в настройках плагина. Вместо iCloud можно указать другой сервер CalDAV.

Синхронизация запускается после изменений в Планировщике, по интервалу (по умолчанию 15 минут, параметр **Интервал синхронизации**), кнопкой **Синхронизировать** и командой **Синхронизировать календарь**.

## Обои и быстрые команды

Вкладка **Блокировка** показывает текущие обои и открывает редактор. Кнопка внизу всех вкладок:

- на iPhone и iPad — **Обновить экран блокировки**: плагин перерисовывает обои и запускает быструю команду «Обои Планировщика», которая ставит их на экран блокировки;
- на компьютере и Android — **Сохранить обои**: плагин только сохраняет PNG в `Планировщик/Обои/<профиль>/`.

**Получить фото** — картинка обоев на сегодня:

- на iPhone, iPad и Android открывается системное меню «Поделиться» — выберите **Сохранить изображение**, и обои окажутся в «Фото»; если меню недоступно, плагин показывает картинку: нажмите и удерживайте её → **Сохранить в Фото**;
- на компьютере (Windows, macOS) открывается предпросмотр с кнопками **Сохранить как…**, **Скопировать**, **Показать в папке** и **Открыть** — перенесите картинку на телефон, например через облако или AirDrop.

Файлы: `lock-ГГГГ-ММ-ДД.png` на каждый из 7 дней и `lock.png` на сегодня — поэтому ночная автоматизация может менять обои неделю без запуска Obsidian. Как собрать команду и настроить автоматизации — в [docs/shortcuts.md](docs/shortcuts.md).

На обоях видны названия задач, в том числе на заблокированном экране.

## Команды

Сочетания клавиш по умолчанию не назначены — их можно задать в **Настройки → Сочетания клавиш**.

| Команда | Что делает |
| --- | --- |
| Открыть задачи | Открывает Планировщик на вкладке **Задачи** |
| Открыть календарь | Открывает вкладку **Календарь** |
| Открыть экран блокировки | Открывает вкладку **Блокировка** |
| Создать задачу | Открывает форму задачи |
| Создать задачу в квадранте «…» | Форма задачи с выбранным квадрантом (по команде на каждый квадрант) |
| Создать событие | Открывает форму события |
| Создать заметку | Открывает форму быстрой заметки |
| Выполнить задачу в активной заметке | Отмечает выполненной задачу, открытую в редакторе |
| Перенести задачу в активной заметке на завтра | Переносит срок открытой задачи на завтра |
| Обновить экран блокировки | Перерисовывает обои и запускает быструю команду (или сохраняет PNG) |
| Синхронизировать календарь | Запускает синхронизацию с «Календарём» iOS |
| Проверить целостность данных | Ищет проблемы и показывает их в **Требуют внимания** |

Ссылки (все содержат `vault=<название хранилища>`):

- `obsidian://planner?vault=…&view=tasks` (или `calendar`, `lockscreen`);
- `obsidian://planner?vault=…&do=new-task&quadrant=do&date=2026-10-21`;
- `obsidian://planner?vault=…&do=open&id=<ULID>`.

## Настройки

Параметры открываются на вкладке **Настройки** Планировщика или в **Настройки → Matrix planner** — содержимое одинаковое:

- без заголовка — корневая папка, перенос выполненных в архив, время напоминания для задач без времени;
- **Календарь** — начало недели, формат времени, календарь для новых событий, показываемые календари;
- **Календарь iOS** — синхронизация через iCloud или другой сервер CalDAV, календари для записи и показа, задачи в календаре, подписки ICS;
- **Экран блокировки** — шаблон, профиль устройства, название быстрой команды;
- **Компаньон** — сведения о будущем приложении для виджетов;
- **Данные** — **Проверить целостность** и список **Требуют внимания**.

## Платформы

| Функция | Windows, macOS | iPhone и iPad | Android |
| --- | --- | --- | --- |
| Задачи, календарь, формы, повторы | Да | Да | Да |
| Синхронизация с «Календарём» iOS (iCloud) | Да | Да | Да |
| Напоминания по задачам | Показывает iPhone, если включены синхронизация и **Задачи в календаре** | Да, через «Календарь» iOS | Показывает iPhone, если включены синхронизация и **Задачи в календаре** |
| Обои | Сохранить PNG, **Получить фото** | Сохранить и поставить быстрой командой, **Получить фото** | Сохранить PNG, **Получить фото** |
| Виджеты | Нет | Нет (приложение-компаньон в разработке) | Нет |

На iPhone с Obsidian 1.11 и новее нижняя панель Планировщика поднимается над плавающей панелью навигации Obsidian.

Если маркер хранилища создан более новой версией плагина, Планировщик работает только для чтения: данные видны, но изменения запрещены до обновления плагина.

## Разработка

```sh
npm install
npm run build   # проверка типов, сборка main.js и styles.css
npm run dev     # сборка с отслеживанием изменений
npm test        # тесты vitest
npm run lint    # ESLint с eslint-plugin-obsidianmd
```

- Исходники — `src/`, стили — `styles/NN-*.css` (собираются в `styles.css`), тесты — `tests/`, общие JSON-фикстуры для плагина и компаньона — `fixtures/`.
- Эталонное хранилище для приёмки — `tests/fixtures/reference-vault.ts`, протокол ручной проверки — [docs/acceptance.md](docs/acceptance.md), результаты — [docs/verification-results.md](docs/verification-results.md).
- Контракты модулей — [docs/contracts.md](docs/contracts.md).

Для проверки в своём хранилище скопируйте `main.js`, `manifest.json` и `styles.css` после `npm run build` в `<хранилище>/.obsidian/plugins/matrix-planner/` и перезагрузите плагин.
