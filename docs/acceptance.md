# Протокол ручной проверки

Протокол приёмки плагина Matrix planner на устройствах по ТЗ §10 и проверкам этапа 0 (ТЗ §8.1). Сквозные сценарии без устройств проверяются автоматически в `tests/acceptance/plugin.test.ts` — их итог записывается в [verification-results.md](verification-results.md).

> Колонка «Результат» заполняется только по факту проверки на устройстве: «Пройдено», «Не пройдено: <что случилось>» или «Не проверялось: <причина>». Пустая ячейка значит, что проверка не выполнялась.

## Подготовка

1. Установите плагин вручную (см. [README](../README.md#установка)) и включите его: **Настройки → Сторонние плагины → Matrix planner**.
2. Подготовьте эталонное хранилище — те же данные, что в `tests/fixtures/reference-vault.ts`:

   | Элемент | Тип и квадрант | Срок и свойства |
   | --- | --- | --- |
   | Стоматолог | Задача, «Важно и срочно» | 11 окт. 2026, 09:00; напоминание «За 15 минут» |
   | Кулинария | Задача, «Важно и срочно» | 11 окт. 2026, 12:30 |
   | Танцы | Задача, «Важно и срочно» | Выполнена 10 окт. 2026 в 13:31 |
   | Стоматолог Лукерья | Задача, «Важно» | 16 окт. 2026, 15:00; высокий приоритет |
   | Хрум чудо-юдо | Задача, «Срочно» | 10 окт. 2026, 17:00; высокий приоритет |
   | Забрать Авито на почте | Задача, «Срочно» | Без срока |
   | Оформить документ о стаже | Задача, «Когда-нибудь» | Без срока; высокий приоритет |
   | Оплатить налоги | Задача, «Когда-нибудь» | Без срока |
   | Концерт | Событие | 21 окт. 2026, 09:00–10:00 |
   | Взять билеты | Быстрая заметка | Дата 21 окт. 2026 |
   | Ежемесячный отчёт | Задача, «Важно», повтор «Каждый месяц» | 31 янв. 2026, 09:00 |
   | День високосного года | Задача, «Когда-нибудь», повтор «Каждый год» | 29 февр. 2028 |

3. Установите на устройстве дату **10 октября 2026** и часовой пояс **Москва** (Europe/Moscow), если проверка зависит от «сегодня». Если менять системную дату нельзя, отметьте это в примечании: подписи «Сегодня»/«Завтра» будут относиться к реальной дате.
4. Для проверки скорости добавьте в папку `Планировщик/Задачи/` 1 000 задач (набор строит `generateLoadTasks()` в `tests/fixtures/reference-vault.ts`).
